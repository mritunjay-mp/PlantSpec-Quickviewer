# Release Notes

## v1.0.0

Initial public release of PlantSpec Quickviewer.

Included features:

- ROI-based multispectral plant image analysis
- Plant mask preview and threshold adjustment
- Vegetation index calculation: ExG, NDVI, GNDVI, NDRE, SAVI, OSAVI
- Thermal_C conversion from raw thermal images
- Wet/dry reference-based CWSI calculation
- Matplotlib bar plot export
- CSV/XLSX result export
- Stepwise PNG export
- Demo dataset

Recommended release assets:

- `PlantSpec_Quickviewer_Windows.zip`
- `PlantSpec_Quickviewer_macOS.zip`
- `PlantSpec_Quickviewer_Linux_x64.zip`
- `PlantSpec_Quickviewer_RPi_Jetson_ARM64.zip`
