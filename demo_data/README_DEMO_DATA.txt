Demo dataset for PlantSpec Quickviewer

This demo contains one Cabbage control capture and one Cabbage test capture.
Each band was center-cropped from the original image using x/y 25% to 75%.

Folder format:
  Cabbage_control_IMG_xxxx/
    blue.tif
    green.tif
    red.tif
    nir.tif
    rededge.tif
    thermal.tif

Use Open Dataset Folder and select this demo_data folder.
